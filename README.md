# Portafolio de Saray Berrio

Portafolio de diseño de producto y desarrollo front-end, con estilo editorial en blanco y negro.

**Ver el sitio: https://saray-b.github.io**

## Qué incluye

- Portada con proyectos, sobre mí y contacto.
- Caso de estudio de **Evalúa**, una plataforma de selección de personal para el sector público (información anonimizada).
- Modo claro por defecto y modo oscuro con un interruptor.
- Sin cookies ni analítica. Funciona sin instalar nada.

## Tecnologías

HTML, CSS y JavaScript sin frameworks. Tipografía Jost, mapa con d3-geo y animación en SVG.

## Ver en tu computador

Abre `index.html` en el navegador. Para servirlo en local:

```
npx serve .
```

## Estructura

```
index.html, project.html   páginas
css/style.css              estilos
js/site.js                 datos del sitio (textos, habilidades, contacto)
js/projects.js             proyectos (uno por objeto)
assets/                    imágenes, fuentes e iconos
tools/                     scripts para optimizar imágenes y generar SEO
```
